# 🧵 Анализ бизнеса по продаже тканей (2018-2020)  
## 📊 Общая картина бизнеса  
- **Стабильный рост**: Бизнес работает с марта 2018 по февраль 2020 года  
- **Выручка**: ~8 млн рублей в год  
- **Чистая маржа**: 48–50% (отличный показатель)  
- **Два канала продаж**: VK (45% выручки) и Интернет-магазин (55% выручки)  

## 🎯 Сильные стороны  
1. **Высокая рентабельность**  
   - Валовая маржа: 55% по обоим каналам  
   - Чистая маржа: 48–50% после всех расходов  
   - Эффективность маркетинга: ROMI = 17.7 (в 3–5 раз выше нормы)  

2. **Сбалансированная география**  
   - 8 городов-лидеров в Московской области  
   - Равномерное распределение: разница между городами всего 15%  
   - Лучшие города: Мытищи, Москва, Реутов (1.1–1.0 млн руб каждый)  

3. **Эффективные бизнес-процессы**  
   - Единая ценовая политика: одинаковая маржа по каналам  
   - Сезонность под контролем: пики в сентябре–ноябре  
   - Стабильный средний чек: 735 рублей  

## ⚠️ Критические проблемы  
1. **Катастрофическое падение притока клиентов**  
2018-03: 420 новых клиентов
2019-12: 1 новый клиент
 - Падение LTV новых клиентов: 7 309₽ → 3 312₽ (**–55%**)  
   - Зависимость от старых клиентов: 66% выручки от когорт 2018 года  

2. **Системные проблемы с данными**  
   - Проблемные товары: P0034, P0072, P0098 постоянно в дефиците  
   - Ошибки в данных: 8 городов с некорректными индексами  
   - Несоответствие инвентаря: разница **2 244 метра** между системами  

3. **Потери из-за отказов**  
   - 10.28% отказов = **1 261** потерянных заказов  
   - **900K руб** потерь выручки ежегодно  
   - **495K руб** потерянной прибыли (**14%** от общей)  

4. **Проблемы со складом**  
   - Рост времени оборота: **1.1 → 3.2 дня** (**+191%**)  
   - Избыточные запасы: рост остатков на **103%** при стабильных продажах  
   - Регулярный дефицит: топ-3 товара отсутствуют до **7 дней**  

## 💡 Ключевые рекомендации  
🚀 **СРОЧНО** (эффект в 30 дней)  
- Увеличить страховой запас для P0034, P0072, P0098  
- Автоматизировать проверку данных клиентов  
- Настроить уведомления о низких остатках  

📈 **СРЕДНЕСРОЧНО** (эффект в 3–6 месяцев)  
- Усилить привлечение новых клиентов (**бюджет +50%**)  
- Снизить отказы на **50%** → **+450K руб** выручки  
- Оптимизировать закупки (**сократить на 30–40%**)  

🎯 **ДОЛГОСРОЧНО** (эффект в 1 год)  
- Внедрить CRM для удержания клиентов  
- Интегрировать системы учета (продажи + инвентарь)  
- Расширить географию в перспективные города
